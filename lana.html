LANA

Logical Attribute Node Aligner

A Python library that weighs two records against each other — attribute by attribute — and tells you which one wins, based on what you decide matters.

pip install ablevlabs PyPI ↗ GitHub ↗

// what it is

Point it at two things. Get a verdict.

Hand lana two records that share the same set of attributes — two job candidates, two laptops, two model runs, two cars — and it compares them field by field, then renders an overall verdict weighted by the priorities you set.

It is not a diff tool. A diff tells you what changed between two versions of the same thing. lana relates two different things and scores the matchup — a question diffs never answer.

Because it only ever sees “records with fields,” it works in any domain. The fighters in the console below are just a fun demo; the same call compares spec sheets, portfolios, or experiment results without changing a line.

// how it works

Three inputs, one clean answer.

01

Same fields

Give lana two dicts that share attribute names, so there’s something to line up.

02

Rate what matters

Score the fields you care about from 1 to 5. A field rated 5 counts five times as much as one rated 1.

03

Flag the inverses

List fields where a smaller number wins — price, latency, weight — so they’re scored the right way.

lana returns a clean dict: who won each field, by how much, and an overall weighted verdict. Whichever record wins a field takes its full priority points; the most points wins. Margins are reported but never secretly sway the result.

// cheat sheet

Everything you need to use it.

install & import

# install once
$ pip install ablevlabs

# then, in any script
from ablevlabs import lana

the smallest call

a = {"name": "Zoro", "score": 90, "cost": 120}
b = {"name": "Sanji",   "score": 80, "cost": 90}

result = lana.compare(a, b)
lana.show(result)

the full call

result = lana.compare(
    a, b,
    priority={"score": 5, "cost": 2},  # 1–5: how much each matters
    lower_better=["cost"],            # cheaper wins
    aliases={"yrs": "years"},        # reconcile field names
)

compare() — options

ArgumentWhat it does
a, bThe two records to compare. Required.
name_a, name_bLabels for the output. If omitted, lana reads a name/model/id field, else uses A / B.
priorityDict of {field: 1–5} — how much each field counts toward the winner.
lower_betterList of fields where a smaller number wins (price, latency, weight).
aliasesDict of {variant: canonical} to reconcile differing field names.

getting the result out

lana.show(result)Readable scorecard in the terminal.
lana.to_json(result)JSON string.
lana.to_csv(result)CSV — opens in Excel / Sheets.
lana.to_markdown(result)Markdown table for docs / GitHub.
lana.to_df(result)pandas DataFrame for analysis.
lana.save(result, "x.json")Saves to disk — format from the extension.
