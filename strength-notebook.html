Predicting Powerlifting Performance¶

A data science case study · Carlos Abel Vivanco / AbleVLabs¶

This project takes a dataset of competition powerlifters and runs the complete machine-learning pipeline: load, explore, clean, visualize, engineer features, model, evaluate, and interpret. The objective is to predict a lifter's competition total from bodyweight, age, sex, and equipment, and to identify what actually drives strength.

The data follows the OpenPowerlifting schema. The file used here is a realistic stand-in so the project is self-contained; the identical code runs on the full public archive by changing one filename.

The tools¶

The analysis uses the standard Python data-science stack: pandas for tabular data, NumPy for numerical work, Matplotlib and Seaborn for visualization, and scikit-learn for modeling.

2. Cleaning the data¶

Each cleaning decision is deliberate and documented, since every row dropped or altered is a modeling choice.

Standardizing the category¶

The Sex values are forced to uppercase so that 'm' and 'M' collapse into a single category.

In [6]:
df["Sex"] = df["Sex"].str.upper()
print(df["Sex"].value_counts())

Sex

Removing impossible values¶

A human competitor does not weigh 9 kg or 1900 kg, so only physically plausible bodyweights are retained. The range is examined first, then filtered.

In [7]:
print("bodyweight range before:", df["BodyweightKg"].min(), "to", df["BodyweightKg"].max())
before = len(df)
df = df[(df["BodyweightKg"] >= 35) & (df["BodyweightKg"] <= 230)]
print(f"removed {before - len(df)} impossible-bodyweight rows")
print("bodyweight range after:", df["BodyweightKg"].min(), "to", df["BodyweightKg"].max())

bodyweight range before: 4.4 to 1018.0
removed 12 impossible-bodyweight rows
bodyweight range after: 44.0 to 182.1

Handling missing values¶

Two situations are treated differently. Because TotalKg is the prediction target, rows missing it are dropped: a model cannot learn from a missing answer. Age is a feature with roughly 9% missing, so rather than discard those rows it is imputed with the median, preserving the remaining information in each row. The median is preferred over the mean because it is robust to outliers. Dropping missing targets while imputing missing features is a standard part of preparing data for modeling.

In [8]:
df = df.dropna(subset=["TotalKg"])          # cannot train on a missing answer
median_age = df["Age"].median()
df["Age"] = df["Age"].fillna(median_age)     # impute the feature
print("median age used for imputation:", median_age)
print("missing values remaining:", int(df.isna().sum().sum()))

median age used for imputation: 37.0
missing values remaining: 0

4. Feature engineering¶

Stronger model inputs are constructed from the raw columns; well-chosen features often matter more than the choice of model.

A ratio feature¶

A strength-to-bodyweight ratio captures pound-for-pound strength, which the raw total does not: a 500 kg total means something different at 60 kg than at 140 kg.

5. Building a predictive model¶

The task is framed as regression: predict TotalKg from bodyweight, age, sex, and equipment. The data is split so the model trains on 80% and is graded on the 20% it has never seen, which is what prevents it from simply memorizing.

In [17]:
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, r2_score

X = model_df.drop(columns=["TotalKg"]); y = model_df["TotalKg"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=1)
print("training on", X_train.shape[0], "lifters, testing on", X_test.shape[0])

training on 23012 lifters, testing on 5754

Baseline: Linear Regression¶

A linear model sets the baseline, judged on two metrics: MAE, the average error in kilograms (lower is better), and R², the fraction of variation in totals the model explains (1.0 is perfect).

In [18]:
lin = LinearRegression().fit(X_train, y_train)
pred_lin = lin.predict(X_test)
print(f"Linear Regression  MAE: {mean_absolute_error(y_test, pred_lin):.1f} kg")
print(f"Linear Regression  R^2: {r2_score(y_test, pred_lin):.3f}")

Linear Regression  MAE: 33.2 kg
Linear Regression  R^2: 0.876

Random Forest¶

A random forest averages many decision trees and captures non-linear effects, such as the age curve seen earlier, that a straight line cannot. It uses the same interface, which is one of the strengths of scikit-learn.

In [19]:
rf = RandomForestRegressor(n_estimators=200, max_depth=14, random_state=1, n_jobs=-1)
rf.fit(X_train, y_train)
pred_rf = rf.predict(X_test)
print(f"Random Forest  MAE: {mean_absolute_error(y_test, pred_rf):.1f} kg")
print(f"Random Forest  R^2: {r2_score(y_test, pred_rf):.3f}")

Random Forest  MAE: 28.3 kg
Random Forest  R^2: 0.903

Summary¶

The project ran a complete pipeline: loading and inspection; cleaning across dirty categories, impossible outliers, and missing values; exploratory analysis; feature engineering; modeling with two algorithms under a proper train/test split; and evaluation with MAE, R², and feature importance. The random forest explained roughly 90% of the variance in totals and predicted within about 28 kg on unseen data, with sex and bodyweight the dominant drivers.

The same pipeline runs on the full 3.9-million-row OpenPowerlifting archive by downloading the bulk CSV and pointing the load step at it; the schema is identical.

Interactive version: an accompanying dashboard turns this analysis into a live walkthrough, with a model that predicts a total from inputs in real time.
