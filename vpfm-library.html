Reading the examples

king_cold is only a variable name — put the lifter's own name (or any label) in its place; it changes nothing. The inputs that actually drive the model are the sets: every (weight, reps) pair you record is what it reads.

// overview

Proximity to failure, quantified.

Reps in reserve is the most useful number in a serious session — and the hardest to judge by feel, especially when fresh. vpfm replaces the estimate with a calculation, and keeps it accurate as fatigue accumulates.

01

Calibrate once

Two all-out sets to failure define the lifter's strength curve. No max attempt, no lab — two sets, entered a single time.

02

Measure every set

Each logged set returns reps in reserve, proximity to failure as a percentage, and an estimated max at that load.

03

Fatigue-aware

A running capacity falls as work accumulates and recovers on rest, so a late set is judged against a lower ceiling than an early one.

// logging a session

Log the work. Read it back.

Every set you record returns a result — reps in reserve, effort, the fatigued max, and the updated capacity. Log an identical set later and it comes back with less in reserve: the fatigue model, doing its job.

session = vpfm.Session(king_cold)

session.do_set(reps=8, load=135, rest=120)   # warm-up
work1 = session.do_set(reps=5, load=295, rest=180)
work2 = session.do_set(reps=5, load=295, rest=0)

work1.rir         # 1.8   reps in reserve
work1.effort      # 0.73  proximity to failure
work2.rir         # 1.4   same set, fewer left
session.capacity  # 0.73  capacity spent

What comes back

Each set hands you a result object with the fields you actually train on: .rir, .effort, .fatigued_max, and the capacity readings before and after.

The two identical 295×5 sets tell the story — 1.8 reps in reserve, then 1.4, because the session has worn the lifter down.

Capacity (0–1) across King_Cold's session — the warm-up barely dents it; the two hard top sets do the work.

Pure calisthenics

Pull-ups, push-ups, dips — the load is fixed, so there is no curve to fit. Supply one fresh max and the model runs unchanged.

The second identical set returns less in reserve — the same fatigue tracking, applied to bodyweight. For weighted or assisted variations, total_load places bodyweight and added plates on a single axis.

Look ahead

Estimate, then a range

Ask what a set will cost before you attempt it, and get the answer as a range rather than false precision: a median reps in reserve plus an 80% interval.

That interval is what makes the model honest — and, later, testable against real outcomes.

session.predicted_rir(reps=5, load=295)
                                  # 1.9   single estimate

vpfm.rir_interval(king_cold, reps=5, load=295)

// programming

From measurement to prescription.

Measuring proximity to failure is half the value. Because vpfm can invert its own model, it also prescribes — which makes it a programming tool, not just a meter.

Training effect is governed largely by proximity to failure: productive work lives in a target reps-in-reserve band. reps_for_rir returns the exact rep count that lands a given load at the effort you choose — so every working set is written to a deliberate proximity to failure instead of a guess. And because capacity falls across the session, the prescription adapts: hold the target fixed, and the reps come down as fatigue rises.

# Hold every working set at 2 RIR on bench (295 lb)
session = vpfm.Session(king_cold)

session.reps_for_rir(target_rir=2, load=295)  # 4.9  -> 5 reps, fresh
session.do_set(reps=5, load=295, rest=180)

session.reps_for_rir(target_rir=2, load=295)  # 4.5  -> fatigue, 4 reps
session.do_set(reps=4, load=295, rest=180)

session.reps_for_rir(target_rir=2, load=295)  # 4.4  -> holds the target
Autoregulation

The same effort, every set

Same target proximity to failure, set after set — the reps come down as fatigue rises, keeping each one productive instead of drifting into junk volume or unplanned failure.

That is the controlled, repeatable stimulus serious programming is built on.

What it does, and doesn't, do
DOESModel strength and fatigue within a session, and control the stimulus — proximity to failure, set by set — with precision.
NOT YETModel between-session adaptation — the multi-week process of getting stronger. That is a separate fitness–fatigue layer, on the roadmap.
SOUsed with a consistent target RIR, progressive load, and periodic re-calibration as the lifter changes, it delivers exactly the stimulus that progressive overload depends on.

// research status

Where it stands.

Research preview

The engine is complete and tested — a clean, proven core with a passing test suite, backed by the formal Vivanco Proximity-to-Failure Model and its derivations.

What remains open: the fatigue constants ship as sensible defaults, not yet fit to real training data. The reps-in-reserve figures are therefore well-formed estimates, not calibrated truth — a precise starting point, treated as such.

Fitting and validating those constants against measured reps-to-failure is the roadmap, and the path from a sound tool to an industry standard.
